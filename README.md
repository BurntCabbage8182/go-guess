# Go Guessing Game

A simple, interactive terminal-based guessing game written in Go.

## Features

- **Dynamic Target:** Generates a random secret number between 1 and 1000.
- **Interactive Feedback:** Tells you if your guess is too high or too low.
- **Input Validation:** Safely handles accidental string/text inputs without crashing the application.

## How to Run

Make sure you have [Go installed](https://go.dev) on your system.

1. Navigate to the project directory:
   ```bash
   cd go-guess
   ```

2. Run the application:
   ```bash
   go run guess.go
   ```

## How to Play

1. The game will prompt you to enter a number.
2. Type your guess and hit `Enter`.
3. Follow the hints until you guess the correct secret number!
